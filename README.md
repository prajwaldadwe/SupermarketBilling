The Supermarket Management System is a console-based application developed using 
C++ and Object-Oriented Programming concepts. The main purpose of this project is to 
automate the process of managing products, billing, inventory, and customer purchases 
in a supermarket environment. 
Traditional supermarket management using manual records can lead to errors, data loss, 
and inefficient billing processes. This system solves these issues by providing a 
computerized solution that maintains product records, generates bills, updates inventory 
automatically, and performs product searches efficiently. 
The application uses file handling for permanent data storage and supports functionalities 
such as: 
• Product addition  
• Product deletion  
• Product searching  
• Inventory management  
• Billing system  
• Discount and tax calculations  
• Promo code support  
• Payment processing
